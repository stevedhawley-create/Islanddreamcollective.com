New Outlook, Outlook on the web (outlook.com / office.com)

  1. Click the gear icon (Settings) at the top right.
  2. Go to Accounts (or Mail) then Signatures.
  3. Click + New signature, name it IDC, and paste (Ctrl+V / Cmd+V) into the big box.
  4. Click Save.
  5. Underneath, under Select default signatures, set For new messages to IDC and For replies/forwards to IDC.
  6. Click Save again. This second save is the step people miss, and it's why the signature doesn't appear on new emails.

Classic Outlook on Windows

  1. File → Options → Mail → Signatures…
  2. Click New, name it IDC, click OK.
  3. Click in the edit box and paste.
  4. On the right, under Choose default signature, check the E-mail account is your IDC address, then set New messages and Replies/forwards to IDC.
  5. Click OK, then OK again to close Options.

Outlook for Mac

  1. Outlook menu → Settings → Signatures.
  2. Click +, name it IDC, paste into the box, then close the edit window to save.
  3. Under Choose default signature, pick your IDC account and set New messages and Replies/forwards to IDC.
